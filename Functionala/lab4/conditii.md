# Paradigma Funcțională - Laboratorul 4

## Cerință
Scrieți o funcție în C++ care primește o structură de liste/tablouri imbricate introdusă de la tastatură (ex: `{1,2[2,2,3],2[2,2,3]}` sau `[2, [2, 3], 4, [4]]`) și returnează o listă unidimensională cu aceleași elemente în ordinea originală (`[1, 2, 2, 2, 3, 2, 2, 2, 3]`).

## Compilare și Rulare
```bash
make run
```
